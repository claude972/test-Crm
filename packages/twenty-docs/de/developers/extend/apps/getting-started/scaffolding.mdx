---

Anstatt Entitätsdateien manuell zu erstellen, können Sie den interaktiven Scaffolder verwenden:

```bash filename="Terminal"
yarn kovaa-lab dev:add
```

Er fordert Sie auf, einen Entitätstyp auszuwählen, führt Sie durch die erforderlichen Felder und schreibt anschließend eine einsatzbereite Datei mit einem stabilen `universalIdentifier` und dem korrekten `defineEntity()`-Aufruf.

Sie können den Entitätstyp auch direkt übergeben, um die erste Eingabeaufforderung zu überspringen:

```bash filename="Terminal"
yarn kovaa-lab dev:add object
yarn kovaa-lab dev:add logicFunction
yarn kovaa-lab dev:add frontComponent
```

## Verfügbare Entitätstypen

| Entitätstyp                | Befehl                                     | Generierte Datei                                          |
| -------------------------- | ------------------------------------------ | --------------------------------------------------------- |
| Objekt                     | `yarn kovaa-lab dev:add object`               | `src/objects/\<name>.ts`                 |
| Feld                       | `yarn kovaa-lab dev:add field`                | `src/fields/\<name>.ts`                  |
| Logikfunktion              | `yarn kovaa-lab dev:add logicFunction`        | `src/logic-functions/\<name>.ts`         |
| Frontend-Komponente        | `yarn kovaa-lab dev:add frontComponent`       | `src/front-components/\<name>.tsx`       |
| Rolle                      | `yarn kovaa-lab dev:add role`                 | `src/roles/\<name>.ts`                   |
| Skill                      | `yarn kovaa-lab dev:add skill`                | `src/skills/\<name>.ts`                  |
| Agent                      | `yarn kovaa-lab dev:add agent`                | `src/agents/\<name>.ts`                  |
| Ansicht                    | `yarn kovaa-lab dev:add view`                 | `src/views/\<name>.ts`                   |
| Navigationsmenüeintrag     | `yarn kovaa-lab dev:add navigationMenuItem`   | `src/navigation-menu-items/\<name>.ts`   |
| Seitenlayout               | `yarn kovaa-lab dev:add pageLayout`           | `src/page-layouts/\<name>.ts`            |
| Seitenlayout-Registerkarte | `yarn kovaa-lab dev:add pageLayoutTab`        | `src/page-layout-tabs/\<name>.ts`        |
| Befehlsmenü-Eintrag        | `yarn kovaa-lab dev:add commandMenuItem`      | `src/command-menu-items/\<name>.ts`      |
| Ansichtsfeld               | `yarn kovaa-lab dev:add viewField`            | `src/view-fields/\<name>.ts`             |
| Verbindungsanbieter        | `yarn kovaa-lab dev:add connectionProvider`   | `src/connection-providers/\<name>.ts`    |
| Zeitachsen-Aktivitätstyp   | `yarn kovaa-lab dev:add timelineActivityType` | `src/timeline-activity-types/\<name>.ts` |

## Was der Scaffolder generiert

Jeder Entitätstyp hat seine eigene Vorlage. Zum Beispiel fragt `yarn kovaa-lab dev:add object` nach:

1. **Name (Singular)** — z. B. `invoice`
2. **Name (Plural)** — z. B. `invoices`
3. **Label (Singular)** — automatisch aus dem Namen befüllt (z. B. `Invoice`)
4. **Label (Plural)** — automatisch befüllt (z. B. `Invoices`)
5. **Ansicht und Navigationseintrag erstellen?** — wenn Sie mit Ja antworten, erzeugt der Scaffolder außerdem eine passende Ansicht und einen Sidebar-Link für das neue Objekt.

Andere Entitätstypen haben einfachere Eingabeaufforderungen — die meisten fragen nur nach einem Namen.

Der Entitätstyp `field` ist detaillierter: Er fragt nach Feldname, Label, Typ (aus einer Liste aller verfügbaren Feldtypen wie `TEXT`, `NUMBER`, `SELECT`, `RELATION` usw.) sowie dem `universalIdentifier` des Zielobjekts.

## Benutzerdefinierter Ausgabepfad

Verwenden Sie den Schalter `--path`, um die generierte Datei an einem benutzerdefinierten Ort abzulegen:

```bash filename="Terminal"
yarn kovaa-lab dev:add logicFunction --path src/custom-folder
```
