# KovaaLab CRM

## Architecture
KovaaLab CRM is composed of five main modules:
- **Boîte**: Module de gestion des boîtes.
- **Calendrier**: Module de gestion des calendriers.
- **Formulaire**: Module de gestion des formulaires.
- **Bot**: Module de gestion des bots.
- **UI**: Module de gestion de l'interface utilisateur.

## Modules par source
- **Boîte**: Gère les différentes boîtes utilisées dans le CRM.
- **Calendrier**: Gère les événements et les rendez-vous.
- **Formulaire**: Gère les formulaires pour la saisie de données.
- **Bot**: Intègre des bots pour l'automatisation des tâches.
- **UI**: Assure une interface utilisateur conviviale.
