Maquette détaillée V3

Prototype statique. Chaque route s’ouvre directement dans l’état décrit, sans interaction préalable.

Cette maquette démontre une interface. Elle ne prouve ni connexion à un fournisseur, ni réception WhatsApp réelle, ni persistance de pipeline, ni campagne opérationnelle. Les commandes marquées « simulé » n’ont aucune API derrière elles.
