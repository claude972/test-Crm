Le proxy expire après **60 minutes à compter de son démarrage**, ferme aussi les connexions actives et n'étend jamais sa durée après actualisation du contrôle public.
- `P0_PREVIEW_CONTROL_FILE` : chemin d'un JSON public fourni par le superviseur, `{ "serverUrl": "https://<preview>.vercel.app", "frontendUrl": "https://<preview>.vercel.app" }`. Les deux origines doivent être identiques, HTTPS, sans identifiants, port, chemin, query ou fragment. Le gate relit ce fichier ; absent ou invalide = 502, aucune requête au backend. Écrire atomiquement par rename côté superviseur. Host et X-Forwarded-Host sont forcés à cette origine ; X-Forwarded-Proto=https et port=443 ; Forwarded supprimé. Origin reste intact pour les protections CORS/CSRF existantes.
- `preview-prepare.mjs prepare <build-dir> <nouveau-staging-dir> <https-tunnel.trycloudflare.com>` : refuse URL non isolée, symlinks/fichiers cachés et répertoire de sortie existant ; copie le bundle sans changer la source. Vérifie un seul slot window._env_ puis injecte REACT_APP_SERVER_BASE_URL vide. Le frontend utilise réellement `window._env_?.REACT_APP_SERVER_BASE_URL || window.location.origin` ; aucune hypothèse import.meta.env. Les routes API proviennent du contrat ApiPath, échouent si sa syntaxe devient inconnue, et précèdent les assets puis le fallback SPA.
- La configuration Vercel ne contient qu'une référence `$P0_ORIGIN_SECRET` dans une transformation de request.headers. Aucun secret n'est sérialisé dans le bundle/configuration. Le superviseur doit fournir le même secret éphémère via GitHub Actions repository secret et variable preview Vercel ; jamais dans Git, contrôle public, journal ou artefact.
