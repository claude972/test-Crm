# Claude mission entry point

At every new mission, read `AGENTS.md`, `DESIGN.md`, `docs/handoff/README.md`, and all instructions closer to the files being reviewed or edited.

The current frontend assignment is `docs/handoff/claude-frontend-p0.md`. Fetch `chore/p0-stabilization` from origin before reading it if this checkout predates the handoff. Read the assignment from that branch; do not automatically merge it into another contributor's checkout.

Begin with the read-only frontend inventory. Feature implementation is gated on the validated common baseline and the agreed backend contract. Never treat missing local changes as permission to recreate or overwrite them.
