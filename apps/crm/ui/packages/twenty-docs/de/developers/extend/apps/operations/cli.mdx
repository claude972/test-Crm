Die `yarn kovaa-lab` CLI ist Ihre Schnittstelle für alles, was mit der App zu tun hat. Vollständige Befehlsliste:

| Befehl                                          | Was es tut                                                                               | Dokumentiert in                                                                                                      |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `dev`                                           | Überwacht Ihre Quelldateien und synchronisiert Änderungen in Echtzeit                    | [Schnellstart](/de/developers/extend/apps/getting-started/quick-start)                                                  |
| `plan`                                          | Metadatenänderungen anzeigen, ohne sie anzuwenden                                        | [Synchronisierung & Wiederherstellung](/de/developers/extend/apps/operations/sync-and-recovery#previewing-changes-plan) |
| `apply`                                         | Metadatenänderungen anwenden, nachdem der Plan angezeigt wurde                           | [Synchronisierung & Wiederherstellung](/de/developers/extend/apps/operations/sync-and-recovery)                         |
| `dev:build`                                     | Die App kompilieren und den API-Client generieren (`--tarball`, um ein `.tgz` zu packen) | [Veröffentlichen](/de/developers/extend/apps/operations/publishing)                                                     |
| `dev:typecheck`                                 | TypeScript-Typprüfung ausführen                                                          | [Tests](/de/developers/extend/apps/operations/testing)                                                                  |
| `dev:add`                                       | Ein Gerüst für eine neue Entität erstellen                                               | [Gerüste](/de/developers/extend/apps/getting-started/scaffolding)                                                       |
| `dev:generate-client`                           | Den typisierten API-Client erneut generieren                                             | diese Seite                                                                                                          |
| `dev:function:exec` / `dev:function:logs`       | Funktionen ausführen und ihre Protokolle streamen                                        | diese Seite                                                                                                          |
| `dev:translations-extract`                      | Übersetzbare Zeichenketten in `locales/`-Kataloge extrahieren                            | [Übersetzungen](/de/developers/extend/apps/operations/translations)                                                       |
| `dev:catalog-sync`                              | Eine Synchronisierung des Marktplatzkatalogs auslösen                                    | [Veröffentlichen](/de/developers/extend/apps/operations/publishing#how-marketplace-discovery-works)                     |
| `app:publish` / `app:install` / `app:uninstall` | Release-Lebenszyklus                                                                     | [Veröffentlichen](/de/developers/extend/apps/operations/publishing) und diese Seite                                     |
| `docker:*`                                      | Den lokalen KovaaLab CRM-Server-Container verwalten                                            | [Lokaler Server](/de/developers/extend/apps/getting-started/local-server)                                               |
| `remote:*`                                      | Serververbindungen verwalten                                                             | diese Seite                                                                                                          |

Jeder Befehl akzeptiert `-r, --remote \<name>`, um ein bestimmtes Remote statt des Standard-Remotes anzusteuern.

## Funktionen ausführen (`yarn kovaa-lab dev:function:exec`)

Eine Logikfunktion manuell ausführen, ohne sie über HTTP, Cron oder ein Datenbankereignis auszulösen:

```bash filename="Terminal"
# Execute by function name
yarn kovaa-lab dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn kovaa-lab dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn kovaa-lab dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the install and uninstall hooks
yarn kovaa-lab dev:function:exec --postInstall
yarn kovaa-lab dev:function:exec --preInstall
yarn kovaa-lab dev:function:exec --uninstall
```

## Funktionsprotokolle ansehen (`yarn kovaa-lab dev:function:logs`)

Ausführungsprotokolle für die Logikfunktionen Ihrer App streamen:

```bash filename="Terminal"
# Stream all function logs
yarn kovaa-lab dev:function:logs

# Filter by function name
yarn kovaa-lab dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn kovaa-lab dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
Dies unterscheidet sich von `yarn kovaa-lab docker:logs`, das die Docker-Container-Logs anzeigt. `yarn kovaa-lab dev:function:logs` zeigt die Funktionsausführungsprotokolle Ihrer App vom KovaaLab CRM-Server.
</Note>

## Generieren des typisierten Clients (`yarn kovaa-lab dev:generate-client`)

Generieren Sie den typisierten API-Client (`kovaa-lab-client-sdk`) erneut aus dem Schema des aktiven Remotes, ohne eine App zu erstellen oder zu synchronisieren. Verwenden Sie ihn, um in jedem Projekt einen typisierten Client zu erhalten – zum Beispiel für einen Backend-Dienst in einem separaten Repository –, der mit Ihrer KovaaLab CRM-Instanz kommuniziert:

```bash filename="Terminal"
# In your project (no KovaaLab CRM app definition required)
yarn add kovaa-lab-sdk kovaa-lab-client-sdk

# Connect to the KovaaLab CRM instance to generate the client from
yarn kovaa-lab remote:add

# Generate the typed client into node_modules/kovaa-lab-client-sdk
yarn kovaa-lab dev:generate-client
```

Importieren Sie dann den Client in Ihrem Code:

```typescript
import { CoreApiClient } from 'kovaa-lab-client-sdk/core';
```

Führen Sie den Befehl erneut aus, wann immer sich Ihr Datenmodell ändert, um die generierten Typen zu aktualisieren.

<Note>
Der Client wird in `node_modules` generiert, daher wird er nicht zusammen mit Ihrem Code eingecheckt. Führen Sie `yarn kovaa-lab dev:generate-client` nach jeder Installation aus (zum Beispiel in einem `postinstall`-Skript oder in CI).
</Note>

## Eine App deinstallieren (`yarn kovaa-lab app:uninstall`)

Entfernen Sie Ihre App aus dem aktiven Arbeitsbereich:

```bash filename="Terminal"
yarn kovaa-lab app:uninstall

# Skip the confirmation prompt
yarn kovaa-lab app:uninstall --yes
```

## Remotes verwalten

Ein **Remote** ist ein KovaaLab CRM-Server, mit dem sich Ihre App verbindet. Während der Einrichtung erstellt das Scaffolding-Tool automatisch eines für Sie. Sie können jederzeit weitere Remotes hinzufügen oder zwischen ihnen wechseln.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn kovaa-lab remote:add

# Connect to a local KovaaLab CRM server (auto-detects port 2020 or 3000)
yarn kovaa-lab remote:add --local

# Add a remote non-interactively (useful for CI)
yarn kovaa-lab remote:add --url https://your-kovaa-lab-server.com --api-key $KOVAALAB_API_KEY --as my-remote

# List all configured remotes
yarn kovaa-lab remote:list

# Set the active remote
yarn kovaa-lab remote:use <name>

# Check that the active remote's authentication is still valid
yarn kovaa-lab remote:status

# Remove a remote
yarn kovaa-lab remote:remove <name>
```

Ihre Anmeldedaten werden in `~/.kovaa-lab/config.json` gespeichert.
