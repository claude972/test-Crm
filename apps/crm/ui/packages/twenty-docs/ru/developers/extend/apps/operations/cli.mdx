CLI `yarn kovaa-lab` — ваш инструмент для всего, что связано с приложением. Полный список команд:

| Команда                                         | Что делает                                                                               | Описано в                                                                                          |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `dev`                                           | Отслеживает исходные файлы и синхронизирует изменения в реальном времени                 | [Краткое руководство](/ru/developers/extend/apps/getting-started/quick-start)                         |
| `план`                                          | Предпросмотр изменений метаданных без их применения                                      | [Syncing & recovery](/ru/developers/extend/apps/operations/sync-and-recovery#previewing-changes-plan) |
| `применить`                                     | Применить изменения метаданных после показа плана                                        | [Syncing & recovery](/ru/developers/extend/apps/operations/sync-and-recovery)                         |
| `dev:build`                                     | Скомпилировать приложение и сгенерировать API‑клиент (`--tarball` для упаковки в `.tgz`) | [Публикация](/ru/developers/extend/apps/operations/publishing)                                        |
| `dev:typecheck`                                 | Запустить проверку типов TypeScript                                                      | [Тестирование](/ru/developers/extend/apps/operations/testing)                                         |
| `dev:add`                                       | Создать каркас новой сущности                                                            | [Создание каркаса](/ru/developers/extend/apps/getting-started/scaffolding)                            |
| `dev:generate-client`                           | Повторно сгенерировать типизированный API‑клиент                                         | эта страница                                                                                       |
| `dev:function:exec` / `dev:function:logs`       | Выполнять функции и транслировать их логи                                                | эта страница                                                                                       |
| `dev:translations-extract`                      | Извлечь переводимые строки в каталоги `locales/`                                         | [Переводы](/ru/developers/extend/apps/operations/translations)                                          |
| `dev:catalog-sync`                              | Запустить синхронизацию каталога маркетплейса                                            | [Публикация](/ru/developers/extend/apps/operations/publishing#how-marketplace-discovery-works)        |
| `app:publish` / `app:install` / `app:uninstall` | Жизненный цикл релиза                                                                    | [Публикация](/ru/developers/extend/apps/operations/publishing) и эта страница                         |
| `docker:*`                                      | Управлять локальным контейнером сервера KovaaLab CRM                                           | [Локальный сервер](/ru/developers/extend/apps/getting-started/local-server)                           |
| `remote:*`                                      | Управлять подключениями к серверам                                                       | эта страница                                                                                       |

Каждая команда принимает параметр `-r, --remote \<name>`, чтобы указать конкретное удалённое подключение вместо подключения по умолчанию.

## Выполнение функций (`yarn kovaa-lab dev:function:exec`)

Запустите логическую функцию вручную, не вызывая её через HTTP, cron или событие базы данных:

```bash filename="Terminal"
# Execute by function name
yarn kovaa-lab dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn kovaa-lab dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn kovaa-lab dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the install and uninstall hooks
yarn kovaa-lab dev:function:exec --postInstall
yarn kovaa-lab dev:function:exec --preInstall
yarn kovaa-lab dev:function:exec --uninstall
```

## Просмотр логов функций (`yarn kovaa-lab dev:function:logs`)

Потоковая передача журналов выполнения логических функций вашего приложения:

```bash filename="Terminal"
# Stream all function logs
yarn kovaa-lab dev:function:logs

# Filter by function name
yarn kovaa-lab dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn kovaa-lab dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
Это отличается от `yarn kovaa-lab docker:logs`, который показывает логи контейнера Docker. `yarn kovaa-lab dev:function:logs` показывает журналы выполнения функций вашего приложения с сервера KovaaLab CRM.
</Note>

## Генерация типизированного клиента (`yarn kovaa-lab dev:generate-client`)

Повторно сгенерируйте типизированный API‑клиент (`kovaa-lab-client-sdk`) из схемы активного удалённого экземпляра, не выполняя сборку или синхронизацию приложения. Используйте это, чтобы получить типизированного клиента в любом проекте — например, в backend‑сервисе в отдельном репозитории — который взаимодействует с вашим экземпляром KovaaLab CRM:

```bash filename="Terminal"
# In your project (no KovaaLab CRM app definition required)
yarn add kovaa-lab-sdk kovaa-lab-client-sdk

# Connect to the KovaaLab CRM instance to generate the client from
yarn kovaa-lab remote:add

# Generate the typed client into node_modules/kovaa-lab-client-sdk
yarn kovaa-lab dev:generate-client
```

Затем импортируйте клиента в свой код:

```typescript
import { CoreApiClient } from 'kovaa-lab-client-sdk/core';
```

Повторно запустите команду при каждом изменении вашей модели данных, чтобы обновить сгенерированные типы.

<Note>
Клиент генерируется внутри `node_modules`, поэтому он не добавляется в ваш репозиторий вместе с кодом. Запускайте `yarn kovaa-lab dev:generate-client` после каждой установки (например, в скрипте `postinstall` или в CI).
</Note>

## Удаление приложения (`yarn kovaa-lab app:uninstall`)

Удалите свое приложение из активного рабочего пространства:

```bash filename="Terminal"
yarn kovaa-lab app:uninstall

# Skip the confirmation prompt
yarn kovaa-lab app:uninstall --yes
```

## Управление удалёнными серверами

**Remote** — это сервер KovaaLab CRM, к которому подключается ваше приложение. Во время настройки скаффолдер автоматически создаст его для вас. Вы можете в любой момент добавлять новые удалённые серверы или переключаться между ними.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn kovaa-lab remote:add

# Connect to a local KovaaLab CRM server (auto-detects port 2020 or 3000)
yarn kovaa-lab remote:add --local

# Add a remote non-interactively (useful for CI)
yarn kovaa-lab remote:add --url https://your-kovaa-lab-server.com --api-key $KOVAALAB_API_KEY --as my-remote

# List all configured remotes
yarn kovaa-lab remote:list

# Set the active remote
yarn kovaa-lab remote:use <name>

# Check that the active remote's authentication is still valid
yarn kovaa-lab remote:status

# Remove a remote
yarn kovaa-lab remote:remove <name>
```

Ваши учётные данные хранятся в `~/.kovaa-lab/config.json`.
