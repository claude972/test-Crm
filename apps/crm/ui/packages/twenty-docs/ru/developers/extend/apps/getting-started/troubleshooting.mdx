---
title: Устранение неполадок
description: Распространенные проблемы при первом запуске — Docker, версия Node, Yarn, зависимости.
---

* **Ошибки Docker** — убедитесь, что Docker Desktop (или демон) запущен перед выполнением `yarn kovaa-lab docker:start`. Сообщение об ошибке укажет правильную команду запуска для вашей ОС.
* **Неверная версия Node** — требуется 24.5+ (`engines.node: ^24.5.0`). Проверьте с помощью `node -v`.
* **Отсутствует Yarn 4** — выполните `corepack enable`.
* **Зависимости повреждены** — `rm -rf node_modules && yarn install`.
* **Ошибки `kovaa-lab-sdk` после обновления до v2.8.0** — он был перенесен из `dependencies` в `devDependencies` в v2.8.0. См. [Структура проекта → Зависимости](/ru/developers/extend/apps/getting-started/project-structure#dependencies).
* **`kovaa-lab dev:build` предупреждает о `kovaa-lab-client-sdk` в разделе `dependencies`** — он предоставляется KovaaLab CRM во время выполнения, поэтому его следует перенести в `devDependencies` рядом с `kovaa-lab-sdk`. См. [Структура проекта → Зависимости](/ru/developers/extend/apps/getting-started/project-structure#dependencies).
